# How to Create React Accumulation Charts of Syncfusion

A quick-start React project demonstrating Syncfusion Accumulation Charts with title, legend, data labels, and tooltip.

Documentation: https://ej2.syncfusion.com/react/documentation/accumulation-chart/getting-started/

Online examples: https://ej2.syncfusion.com/react/demos/#/material/chart/default-pie

## Project Overview

Minimal React starter showing Syncfusion Accumulation Chart integration and basic chart configuration.

## Features

- Syncfusion Accumulation Chart integration
- Title, legend, data labels, and tooltip examples
- Editable sample data in src/data.js

## Prerequisites

Node.js (LTS) and npm; Visual Studio Code is recommended.

## Installation

1. Clone the repository.
2. Open in Visual Studio Code.
3. Run `npm install`.
4. Run `npm start`.

## Usage

Edit `src/data.js` and `src/App.tsx` to change data and chart options. Visit http://localhost:3000.

## Configuration

Adjust chart options per the linked Syncfusion documentation.

## Contributing & Support

Open issues for bugs or questions.

## Troubleshooting

If `npm install` fails, remove `node_modules` and reinstall or update Node/npm.
